# # Bienvenido al Laboratorio de Sins of The Spire

# ¡Bienvenidos a nuestro laboratorio!

# En este proyecto exploraremos el funcionamiento de diferentes técnicas de renderizado mediante el desarrollo de **Sins of The Spire**, poniendo en práctica conceptos fundamentales de los gráficos por computadora.

# A lo largo de este laboratorio trabajaremos con la rasterización mediante *Scanline*, el trazado de rayos (*Ray Tracing*) y la oclusión ambiental (*Ambient Occlusion*), implementando diferentes métodos para representar objetos, luces, sombras y reflejos.

# También realizaremos pruebas de rendimiento para comparar los tiempos de renderizado, las resoluciones y los resultados visuales de cada técnica.

# Este espacio representa el trabajo en equipo, la experimentación y la aplicación de nuestros conocimientos en programación y gráficos 3D.
